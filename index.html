Features

Multi-clip timeline

Import videos and photos, then trim, split, reorder and delete clips. Choose the aspect ratio for each project (9:16 by default).

GPU colour looks

Real-time looks and chroma key written as GLSL fragment shaders, plus brightness, contrast and saturation filters.

Transitions & text

Fade and dissolve transitions. Text overlays with font, colour, position and timing.

Audio studio

Background music with trim, offset and volume, plus voice-over recording and bundled loops.

Undo / redo + autosave

Every edit is stored as a database row, so history and autosave come almost free.

Export & share

An FFmpeg filter graph renders the MP4 with hardware encoding and a progress notification, then saves it to the gallery. FCPXML export is also available.

Architecture

Screens & widgets   what the user sees        ref.watch() → auto-redraw
        ↓                                      ↑ streams
Providers           Riverpod glue
        ↓                                      ↑
Database            Drift / SQLite: the single source of truth
        ↑ writes
Services            import, probe, thumbnails
Export pipeline     DB rows → FFmpeg filter graph → MP4

Your original media is never modified. An edit is just a number in a row ("trim clip 3 from 1.0 s to 4.0 s"), and the export step combines those rows into one new video.

Install

  1. On your Android phone, tap Download APK.
  2. Open the downloaded file. If asked, allow Install unknown apps.
  3. Tap Install, then open ClipForge.
