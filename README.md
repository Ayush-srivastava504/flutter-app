# ClipForge — mobile video editor (Flutter)

Import clips and photos, trim/reorder, add filters, transitions, music and text, then export an MP4.
Everything you edit is stored as small database rows; your original media is never modified.

**New to the codebase? Read `docs/APP_GUIDE.md` first.**

## First-time setup
```bash
flutter pub get
flutter analyze && flutter test      # should be green before you change anything
scripts/dev.sh run                   # debug run on a connected Android phone (arm64)
```
`*.g.dart` files are generated by Drift and are committed, so you only need
`scripts/dev.sh gen` after you change a table in `lib/data/project_database.dart`.

## Daily commands
| Command | What it does |
|---|---|
| `scripts/dev.sh run` | Debug run, ARM64 only (fast) |
| `scripts/dev.sh check` | analyze + tests |
| `scripts/dev.sh gen` / `watch` | regenerate database code |
| `scripts/dev.sh graph` | prove the FFmpeg export graph on your computer |
| `scripts/dev.sh logs` | export logs from the phone |

Old per-phase notes live in `docs/history/`.
